# Cifras de teste

Cifras **autorais** (letras escritas para os testes, sem relação com músicas existentes) usadas para verificar a classificação de linhas da formatação automática.

Cada linha começa com o rótulo esperado e `|`:

| Rótulo | Tipo |
|---|---|
| `C` | linha de cifra |
| `L` | letra |
| `T` | tablatura |
| `H` | cabeçalho de seção |
| `M` | anotação pessoal (`#`) |
| `D` | marcação (`{refrao:1}`, `{/tab}`…) |
| `B` | linha vazia |
