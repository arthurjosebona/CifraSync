# Decisões de arquitetura (ADR)

Cada decisão técnica relevante vira um arquivo `NNNN-titulo-curto.md`, criado quando o `PLAN.md` que a introduz é aprovado.

Modelo:

```markdown
# NNNN — Título

**Status:** Proposta | Aceita | Substituída por NNNN
**Data:** AAAA-MM-DD
**Origem:** docs/specs/NN-feature/PLAN.md

## Contexto
## Decisão
## Consequências
## Alternativas consideradas
```

Ainda não há ADRs: as decisões de stack serão tomadas no PLAN de [`specs/01-mvp`](../specs/01-mvp/SPEC.md).
