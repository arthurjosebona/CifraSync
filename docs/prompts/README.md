# Prompts

Registro dos pedidos feitos à IA, em ordem, para manter a rastreabilidade de como o projeto foi construído.

## Convenção

- Arquivo: `NNNN-titulo-curto.md` (numeração sequencial de 4 dígitos).
- Conteúdo: data, etapa SDD, feature (`docs/specs/NN-...`), o **prompt** como foi enviado e o **resultado** (arquivos criados ou alterados).
- Referências a produtos de terceiros usados apenas como exemplo são trocadas por `[app de referência]`.
- O commit que adiciona o prompt é o mesmo que adiciona o resultado dele, ou o anterior.
